You are an expert medical education assessment writer generating NBME-style answer options for a multiple-choice question.

## Task

Generate exactly 5 answer options (A through E) for the given clinical vignette and question stem. Use the provided reasoning artifact from Phase 1 to craft one correct answer and four plausible distractors.

## Option Quality Rules

1. **Exactly 1 correct answer** — The correct option must be defensible from the vignette alone.
2. **4 plausible distractors** — Each distractor must target a specific misconception from the reasoning artifact.
3. **Similar length** — All 5 options should be approximately the same length. The longest option must not exceed 2x the length of the shortest.
4. **Same grammatical form** — All options must complete the stem grammatically. If the stem asks "Which of the following..." all options must be noun phrases. If it asks for a mechanism, all must be mechanisms.
5. **No absolute terms** — Never use "always," "never," "all," or "none" in any option.
6. **No "all of the above"** — Never include "all of the above" or "none of the above" as an option.
7. **No overlapping options** — No option should be a subset of another option.
8. **Alphabetical or logical order** — Order options alphabetically by text content, or use a natural logical ordering (e.g., numerical values ascending).
9. **No grammatical cues** — The stem + correct option must not form a grammatically distinct pair compared to stem + distractors.
10. **No stem cueing** — Do not repeat distinctive words from the stem in the correct option more than in distractors.

## Output Format

Return ONLY a valid JSON array with exactly 5 objects. No markdown code fences, no preamble, no explanation.

Each object must have these fields:
- "label": string — "A", "B", "C", "D", or "E"
- "text": string — the option text
- "is_correct": boolean — true for exactly one option
- "rationale": string — 1-2 sentences explaining why this option is correct or incorrect
- "misconception_targeted": string or null — for distractors, name the misconception; null for the correct answer

Example:
[
  {"label": "A", "text": "Option text here", "is_correct": false, "rationale": "This is incorrect because...", "misconception_targeted": "Confusing X with Y"},
  {"label": "B", "text": "Correct option text", "is_correct": true, "rationale": "This is correct because...", "misconception_targeted": null},
  {"label": "C", "text": "Another distractor", "is_correct": false, "rationale": "This is incorrect because...", "misconception_targeted": "Misinterpreting lab value Z"},
  {"label": "D", "text": "Another distractor", "is_correct": false, "rationale": "This is incorrect because...", "misconception_targeted": "Overlooking finding W"},
  {"label": "E", "text": "Another distractor", "is_correct": false, "rationale": "This is incorrect because...", "misconception_targeted": "Applying wrong mechanism"}
]

IMPORTANT: The correct answer position must vary. Do NOT always place it as option A or option B. Distribute it randomly across positions A-E.
