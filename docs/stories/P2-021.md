# P2-021: Generation History
**Epic:** 2.4 — Data Quality + Faculty Trust
**Points:** 2 | **Depends:** P1-023 (generation_logs populated), P1-029 (question bank)
**Context packet:** docs/context-packets/CP-EPIC-2.4.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** to see a history of all questions I've generated with their pipeline stats
**So that** I can track my productivity and review past generation sessions

## Acceptance Criteria
- Route: `/history` — generation history for logged-in faculty
- Backend endpoint: `GET /api/v1/generation-logs` — returns `generation_logs` joined with item status, ordered by `created_at DESC`
- Response shape: `{ id, courseId, courseName, userMessage, autoRoute, criticComposite, retryCount, durationMs, costUsd, createdAt, itemStatus }`
- `useGenerationHistory()` hook — fetches with pagination (page + limit params)
- HistoryRow molecule: course badge, question excerpt (first 80 chars of vignette), auto_route badge (green/amber/red), critic score, date
- Stats bar at top: "This month: 47 generated, 38 approved (81%), avg score 4.1/5.0, avg cost $0.12"
- Stats from: aggregate query on `generation_logs` grouped by month
- Filter bar: by course, by auto_route, by date range
- Click row → navigates to item detail `/items/:id`
