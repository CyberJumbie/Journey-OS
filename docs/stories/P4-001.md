# P4-001: Item Bank View (/repository/item-bank)
**Epic:** 4.1 — Item Bank + Management
**Points:** 3 | **Depends:** P1-029 (basic question bank), P2-001 (tags exist), P2-004 (critic scores)
**Context packet:** docs/context-packets/CP-EPIC-4.1.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** a rich, filterable item bank with multi-dimension filtering
**So that** I can find specific questions quickly and understand my bank's composition at a glance

## Acceptance Criteria
- Route: `/repository/item-bank` (wires existing `ItemBankBrowser` prototype screen)
- Endpoint: `GET /api/v1/item-bank` — matches `ItemBankResponse` shape exactly (see 06_SCREEN_BACKEND_MAP.md)
- Filters (all combinable): `system`, `difficulty`, `bloom`, `status`, `format`, `search`, `page`, `limit`
- Advanced filters (Phase 4 additions): `critic_min` (float), `has_toulmin` (bool), `task_shell_id`, `auto_route`, `batch_id`
- Sort options: `created_at DESC`, `critic_composite_score DESC`, `bloom_level ASC`, `usmle_system`
- Pagination: 20 per page default, `total_pages` in response
- Item card: shows stem excerpt (120 chars), system badge, Bloom badge, difficulty badge, critic score pill, status badge, Toulmin indicator
- Bulk select: checkboxes + "Add to Exam" button (links to `/exams/new?itemIds=X,Y,Z`)
- Export button: "Export CSV" → `GET /api/v1/item-bank/export.csv` with current filters applied
- `useItemBank(filters)` hook — TanStack Query with filter params as query key

## Smoke Test
```bash
# Filtered query
curl "localhost:3001/api/v1/item-bank?system=Cardiovascular+System&bloom=3&status=approved&limit=5" \
  -H "Authorization: Bearer $JWT" | jq '{total, items: (.items | length)}'
# Expected: total ≥ 0, items ≤ 5, all returned items have bloom_level=3 and status=approved

# CSV export
curl "localhost:3001/api/v1/item-bank/export.csv?status=approved" \
  -H "Authorization: Bearer $JWT" -o items.csv
wc -l items.csv
# Expected: ≥ 2 lines (header + at least one row)
```
