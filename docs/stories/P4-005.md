# P4-005: Exam Builder (/exams/new)
**Epic:** 4.2 — Exam Assembly
**Points:** 5 | **Depends:** P4-001 (item bank), P4-006 (MIP solver)
**Context packet:** docs/context-packets/CP-EPIC-4.2.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** a constraint-based exam builder that automatically selects the optimal question set
**So that** I can assemble a well-balanced exam in minutes instead of hours

## Acceptance Criteria
- Route: `/exams/new` (wires existing `ExamAssembly` prototype screen)
- Constraint form (Step 1 — "Blueprint"):
  - Exam name (text)
  - Course (select)
  - Total questions: 1–200 (number input)
  - Time limit: minutes (number input)
  - Bloom distribution: sliders per level (Remember/Understand/Apply/Analyze/Evaluate/Create, must sum to 100%)
  - USMLE system distribution: % per system (optional — leave blank = unconstrained)
  - Difficulty mix: Easy/Medium/Hard % (must sum to 100%)
  - Exclude items: multi-select from past exam IDs (avoid repeating questions)
  - Min critic score: 0–5 slider (default 3.5)
- "Generate Exam" button → `POST /api/v1/exams` with constraint object → calls MIP solver
- Loading state: "Solving constraints..." spinner (MIP solver may take 5–30 seconds)
- Step 2: preview generated exam (see P4-007)
- Response matches `Exam` shape from 06_SCREEN_BACKEND_MAP.md exactly
- Blueprint validation panel: shows system_distribution, difficulty_balance each with pass/warn/fail badges
