# P3-013: Course Detail View (/courses/[id])
**Epic:** 3.3 — Faculty Dashboard + Coverage Visualization
**Points:** 3 | **Depends:** P3-011 (dashboard), P3-007 (heatmap data)
**Context packet:** docs/context-packets/CP-EPIC-3.3.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** a per-course view showing coverage, recent questions, and weekly syllabus breakdown
**So that** I can manage each course independently and see where I need to generate more questions

## Acceptance Criteria
- Route: `/courses/:id` (wires existing `CourseDashboard` prototype screen)
- Endpoint: `GET /api/v1/courses/:id/detail` — single-call aggregate
- Response matches prototype shape exactly (see 06_SCREEN_BACKEND_MAP.md):
  ```typescript
  interface CourseDashboardData {
    course: Course;
    coverage_percentage: number;
    recent_questions: RecentQuestion[];
    weeks: Week[];   // syllabus week breakdown with topic list + question counts
  }
  ```
- Weeks: derived from `ContentChunk.metadata.weekNumber` (set during ingestion if syllabus has week headings)
- Per-week: `topic_count`, `question_count`, `target_count` (Phase 3: target = 5 per week, hardcoded)
- Coverage badge: green/amber/red based on question_count vs target_count per week
- "Generate for this week" button per week row → `/workbench?courseId=X&weekNumber=N`
