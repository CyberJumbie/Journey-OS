# P2-015: Toulmin Argument Generation
**Epic:** 2.3 — ECD + TaskShells
**Points:** 5 | **Depends:** P2-001 (tagger), P1-023 (item persisted)
**Context packet:** docs/context-packets/CP-EPIC-2.3.md
**Specialist:** @pipeline-specialist

**As a** faculty member
**I want** every generated question accompanied by a Toulmin evidentiary argument
**So that** I can verify that the question is grounded in evidence and teaches a specific claim

## Acceptance Criteria
- New node: `backend/src/pipeline/nodes/ToulminGeneratorNode.ts` — runs after tagger, before critic_agent
- Model: Claude Sonnet (quality matters for ECD structure)
- 6 Toulmin fields:
  1. **claim** — What the correct answer asserts ("Atherosclerosis causes luminal narrowing via plaque")
  2. **data** — Evidence from the content chunks used for context
  3. **warrant** — Why the data supports the claim
  4. **backing** — Authoritative grounding (guideline, textbook chapter)
  5. **rebuttal** — Why the distractors are wrong
  6. **qualifier** — Conditions / limitations on the claim
- Prompt in: `backend/src/pipeline/prompts/toulmin-generator-system.txt`
- Storage: `assessment_items.toulmin JSONB` — all 6 fields stored as JSON
- STATE_DELTA: `{ toulmin: { claim, data, warrant, backing, rebuttal, qualifier } }` — visible in right panel under "Evidence Chain" collapsible
- TEXT_MESSAGE: "Building evidence chain..."
- If any field empty: Sonnet asked to fill with "N/A" rather than omitting the key
