# P2-007: Review Mode Pipeline
**Epic:** 2.2 — Review Mode + Bulk Generation
**Points:** 5 | **Depends:** P2-003 (full validator), P2-004 (critic), P1-023 (items exist)
**Context packet:** docs/context-packets/CP-EPIC-2.2.md
**Specialist:** @pipeline-specialist

**As a** faculty member
**I want** to load an existing question in the workbench and edit it conversationally
**So that** I can improve questions without starting from scratch

## Acceptance Criteria
- WorkbenchState `mode: 'review'` triggers a separate pipeline branch in `graph.ts`
- Review pipeline nodes (3 new nodes):
  1. `load_review_question` — loads existing item from Supabase by `itemId`, populates WorkbenchState
  2. `apply_edit` — Sonnet applies the faculty's conversational instruction to the loaded item
  3. `revalidate` — runs full 30-rule validator + Cover the Options on edited content
- After `revalidate`: flows into existing `critic_agent → review_router` nodes (reuse, no duplication)
- New node files:
  - `backend/src/pipeline/nodes/LoadReviewQuestionNode.ts`
  - `backend/src/pipeline/nodes/ApplyEditNode.ts`
  - `backend/src/pipeline/nodes/RevalidateNode.ts` (thin wrapper calling ValidatorNode logic)
- Prompts:
  - `apply-edit-system.txt` — instructs Sonnet to make surgical edits, preserve structure
- `graph.ts`: mode-based branching at init node — `mode === 'review'` → skip generation nodes, enter review branch
- Supabase: on save, create new version row (immutable history) — `assessment_item_versions` table
- `assessment_item_versions`: `id, item_id, vignette, stem, options JSONB, edit_instruction, edited_by, created_at`
