# P3-009: PageRank + Betweenness Centrality on SubConcept Graph
**Epic:** 3.2 — USMLE Gap Detection
**Points:** 3 | **Depends:** P3-004 (SubConcepts deduplicated, rich graph exists)
**Context packet:** docs/context-packets/CP-EPIC-3.2.md
**Specialist:** @backend-specialist

**As a** system
**I want** weekly graph centrality scores computed for all SubConcepts
**So that** gap priority scoring and the coverage map can highlight foundational concepts

## Acceptance Criteria
- Inngest weekly cron: `backend/src/inngest/graph-analytics.function.ts`
- Schedule: every Sunday at 03:00 UTC (`cron: '0 3 * * 0'`)
- Uses Neo4j Graph Data Science (GDS) library (available on Aura Professional tier)
  - If GDS unavailable (Aura Free): fallback to manual PageRank via Cypher iteration (see CP-EPIC-3.2.md)
- Algorithms:
  1. **PageRank** on `SubConcept` nodes via `TEACHES` + `MAPS_TO` edges → `pagerank_score FLOAT`
  2. **Betweenness Centrality** on SubConcept subgraph → `betweenness_score FLOAT`
- Store results in Neo4j as node properties: `sc.pagerank = 0.043, sc.betweenness = 0.12`
- Also write to Supabase `sub_concept_analytics (sub_concept_id, pagerank, betweenness, computed_at)` for SQL queries
- Admin endpoint: `GET /api/v1/admin/graph-analytics/latest` — returns last run timestamp + top 10 by pagerank
