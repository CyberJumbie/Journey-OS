# P1-002: Provision Infrastructure

**Epic:** 1.1 — Infrastructure & Spike
**Priority:** P0
**Points:** 2
**Status:** ready
**Depends on:** P1-001

---

## Story

As a **developer**,
I want Neo4j Aura, Supabase, and Vercel provisioned with connection credentials in `.env`,
so that all subsequent stories can connect to real databases.

---

## Acceptance Criteria

- [ ] **AC1:** Neo4j Aura instance running; `NEO4J_URI`, `NEO4J_USERNAME`, `NEO4J_PASSWORD` in `.env`; test query `MATCH (n) RETURN count(n)` returns 0 (empty)
- [ ] **AC2:** Supabase project created; `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` in `.env`
- [ ] **AC3:** Vercel project linked to repo; `NEXT_PUBLIC_API_URL` in `.env`; `vercel env pull` works
- [ ] **AC4:** `GET /api/health` response includes `{ neo4j: "ok", supabase: "ok" }` confirming both connections live
