## ⚠️ CRITICAL: Raw Text Will Fail — Read SOL-006 First

`pdf-parse` (npm, the source doc default) produces raw `.txt`. This **silently corrupts** MSM syllabi:

| Failure | Impact on Pipeline |
|---|---|
| Table collapse | Dates merge with topics; wrong lecturer assigned to sessions |
| Lost color-coding | FoM1 modality info (sync vs async) permanently destroyed |
| Broken hierarchies | Anatomy sub-objectives orphaned from parents → wrong USMLE mapping |
| Noise not separable | Blank checklists and policy text extracted as if they're learning objectives |

**Decision tree (see SOL-006 for full detail):**

```
Simple, single-column PDF → Option C: pdf-parse (fast, no external dep)
Multi-column or table-heavy → Option A: LlamaParse API (recommended for Phase 1)
High volume or offline → Option B: pdfplumber Python service
```

**Phase 1 recommendation: LlamaParse API (Option A).** Add `LLAMAPARSE_API_KEY` to env.

## Updated ParsedDocument Type (add to packages/shared-types/src/pipeline.ts)

```typescript
interface ParsedDocument {
  markdown: string
  pages: { pageNumber: number; markdown: string; hasTable: boolean }[]
  metadata: {
    title?: string
    author?: string
    pageCount: number
    extractionMethod: 'llamaparse' | 'pdfplumber' | 'pdf-parse'
    hasTableContent: boolean
    hasNestedObjectives: boolean
  }
}
```

## Known Unrecoverable Limitation

FoM1 color-coding (blue = synchronous, peach = asynchronous) is permanently lost by any text extractor.
Document this in a comment in the parser service. The Classifier node (SOL-007, P1-013) will treat all sessions as required unless context states otherwise.
