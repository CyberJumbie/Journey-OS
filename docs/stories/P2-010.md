# P2-010: Bulk Generation via Inngest
**Epic:** 2.2 — Review Mode + Bulk Generation
**Points:** 8 | **Depends:** P2-005 (full pipeline), P1-023 (single generation works)
**Context packet:** docs/context-packets/CP-EPIC-2.2.md
**Specialist:** @backend-specialist

**As a** faculty member
**I want** to request 10–20 questions at once and have them generated in the background
**So that** I can step away and come back to a queue of questions ready for review

## Acceptance Criteria
- Inngest installed: `npm install inngest` in backend
- Inngest client: `backend/src/lib/InngestClient.ts` (Singleton)
- Event: `journey/batch.requested` → payload: `{ batchId, courseId, topicIds, count, userId }`
- Inngest function: `backend/src/inngest/bulk-generation.function.ts`
  - Concurrency: max 5 parallel generations (Inngest `concurrency: { limit: 5 }`)
  - Per-item: calls existing single-generation pipeline
  - Progress: emits `journey/batch.item.completed` after each item
  - On error: marks item `status: 'failed'`, continues batch (never aborts full batch on single failure)
- New Supabase tables: `bulk_batches`, `bulk_batch_items`
  ```sql
  bulk_batches: id, course_id, user_id, total_count, completed_count, failed_count, status, estimated_cost, created_at
  bulk_batch_items: id, batch_id, item_id, status, error_message, created_at
  ```
- API endpoint: `POST /api/v1/batches` → creates batch, fires Inngest event, returns `{ batchId }`
- API endpoint: `GET /api/v1/batches/:id` → returns batch + item statuses
- DualWriteService: each batch item goes through full pipeline including tagger + critic

## Smoke Test
```bash
# Request a batch of 5 items
curl -X POST localhost:3001/api/v1/batches \
  -H "Authorization: Bearer $JWT" \
  -H "Content-Type: application/json" \
  -d '{"courseId":"medi-531","topicIds":["cardiovascular","renal"],"count":5}'
# → { "batchId": "batch_abc123" }

# Poll batch status
sleep 60
curl "localhost:3001/api/v1/batches/batch_abc123" -H "Authorization: Bearer $JWT"
# Expected: { completed_count: 5, failed_count: 0, status: 'completed' }
```
