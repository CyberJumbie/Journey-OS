## Story

As a **developer**,
I want the MSM institutional structure seeded in Neo4j (~65–70 nodes),
so that courses, sections, and sessions have a navigable graph structure.

---

## Acceptance Criteria

- [ ] **AC1:** Seeder at `services/kg-seeder/src/seed-layer1.ts` (TypeScript, uses `neo4j-driver`)
- [ ] **AC2:** Nodes created: Institution, School, Program, ProgramTrack, AcademicYear, CurricularPhase, Block, Course, Section, AcademicTerm, ILO
- [ ] **AC3:** Relationships created: `HAS_SCHOOL`, `OFFERS_PROGRAM`, `HAS_TRACK`, `IN_YEAR`, `HAS_PHASE`, `CONTAINS_BLOCK`, `OFFERS_COURSE`, `HAS_SECTION`, `IN_TERM`, `HAS_ILO`
- [ ] **AC4:** Uniqueness constraint created before seeding: `CREATE CONSTRAINT course_code_unique IF NOT EXISTS FOR (c:Course) REQUIRE c.code IS UNIQUE`
- [ ] **AC5:** Idempotent — running twice produces same node count (~65–70)
- [ ] **AC6:** Seed data from MSM course catalog (22+ courses, MEDI codes, 4 years)
