**I want** the validator to catch all 30 NBME structural rules plus semantic correctness
**So that** every question that passes auto-review is genuinely exam-ready

## Acceptance Criteria

### Structural Rules (pure TypeScript — no AI)
Expand from 10 to 30 rules. New rules to add:
- R011: Vignette has patient age and sex
- R012: No "all of the above" / "none of the above" options
- R013: Options are grammatically parallel
- R014: No option repeats content from stem
- R015: Correct answer is not consistently option A (check batch stats)
- R016: Distractors are plausible (non-trivially wrong)
- R017: Stem ends with a question mark or clear lead-in
- R018: No "trick" qualifiers (always, never, only, must)
- R019: Vignette does not mention diagnosis in the stem
- R020: All options approximately equal length (±40% of mean)
- R021–R030: Medical accuracy checkers — drug names real, anatomy terms correct, units appropriate, lab values in physiologic range, clinical timeline plausible, etc.

### "Cover the Options" Semantic Validator (Sonnet)
- New function: `coverTheOptions(item: GeneratedItem): Promise<ValidationResult>`
- Uses Sonnet to simulate: "If I read only option X and the vignette, is X defensible?"
- Returns: `{ allOptionsAddressedByStem: boolean, weakOptions: string[], recommendation: string }`
- Prompt in: `backend/src/pipeline/prompts/cover-the-options-system.txt`
- Only runs if all 30 structural rules pass (expensive — do not waste on broken items)
- Result added to `validationResults` array in WorkbenchState

### Storage
- `assessment_items.validation_results JSONB` — full results array
- `assessment_items.validation_passed BOOLEAN` — quick filter
