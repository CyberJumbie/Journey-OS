## Acceptance Criteria
- Apply 3-layer surface model (Cream/Parchment/White) consistently to all routes built so far:
  - Page background: `#f5f3ef` (cream)
  - Sidebar + cards: `#faf9f6` (parchment)
  - Input fields + reading areas: `#ffffff` (white)
- Typography applied globally:
  - Headings: Lora 600 (load via `next/font`)
  - Body: Source Sans 3 400
  - Labels/badges/timestamps: DM Mono 400 uppercase
- Sidebar: collapsible, 72px collapsed → 240px expanded, Navy Deep `#002c76` background
  - Links: Dashboard, Courses, Generate, Question Bank, Analytics, History
- Header: frosted glass on scroll, white background, NotificationBell (from P2-012), user avatar
- All status badges use correct colors: Green=approved, Amber=pending/review, Red=rejected/failed
- `DashboardTemplate` organism: wraps all logged-in routes with sidebar + header
- Mobile: sidebar collapses to bottom nav on < 768px breakpoint
- Audit: manually walk through all routes — no hardcoded hex colors, no raw font-family strings
