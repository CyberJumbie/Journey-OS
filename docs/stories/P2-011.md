**Context packet:** docs/context-packets/CP-EPIC-2.2.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** to see the progress of a bulk generation batch in real time
**So that** I know when my questions are ready and can intervene on failures

## Acceptance Criteria
- Route: `/batches` — lists all batches for current user
- Route: `/batches/:id` — batch detail view with per-item progress
- `useBatches()` hook — polling `GET /api/v1/batches` every 5s (no WebSocket required in Phase 2)
- `useBatchDetail(batchId)` hook — polling `GET /api/v1/batches/:id` every 3s while `status !== 'completed'`
- BatchCard organism: `batch_id`, topic count, progress bar `completed/total`, estimated cost, status badge
- BatchItemRow molecule: item excerpt, status (pending/running/completed/failed), Bloom tag, USMLE tag
- Failed items: show error message + "Retry" button → `POST /api/v1/batches/:id/items/:itemId/retry`
- Completed batch: "Review All" button → opens review queue filtered by `batch_id`
- No God Components — BatchDetailView splits into BatchHeader + BatchProgressBar + BatchItemList
