**As a** faculty member
**I want** every generated question scored by an independent AI critic
**So that** I can trust auto-approved questions without reviewing each one manually

## Acceptance Criteria
- Node: `backend/src/pipeline/nodes/CriticAgentNode.ts` — runs after `validator`, before `review_router`
- Model: `claude-opus-4-6` — Phase 2+ ONLY. Never Opus in Phase 1 nodes.
- 6-metric scoring rubric (each 1–5 scale, stored individually):
  1. **clinical_accuracy** — Is the medical content correct?
  2. **vignette_realism** — Does the patient presentation feel real?
  3. **distractor_quality** — Are wrong answers genuinely plausible?
  4. **bloom_alignment** — Does the question match the claimed Bloom level?
  5. **nbme_compliance** — Does it follow NBME format conventions?
  6. **educational_value** — Would answering this teach something meaningful?
- Composite score: average of 6 metrics, stored as `critic_composite_score FLOAT`
- Reasoning: `critic_reasoning TEXT` (max 300 words) — stored in `assessment_items`
- Prompt in: `backend/src/pipeline/prompts/critic-agent-system.txt`
- STATE_DELTA: `{ criticScores: [...], criticComposite: 4.2 }` — shown in right panel
- TEXT_MESSAGE: "Critic review: {composite}/5.0 ({verdict})"
- Cost awareness: log Opus token usage in `generation_logs.critic_input_tokens` + `critic_output_tokens`

## Failure Modes
1. Opus times out (> 30s) → set `critic_composite_score: null`, continue to review_router with `auto_route: 'faculty_review'`
2. Opus returns malformed scoring → parse gracefully, log warning, do not throw
3. Cost explosion — add circuit breaker: if monthly Opus spend > $50, disable CriticAgent and log alert
