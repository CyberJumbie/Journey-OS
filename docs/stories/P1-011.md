## ⚠️ Key Difference from Naive Chunking

The original AC specified "split on double-newline first" — this is wrong for Markdown. Markdown tables use `\n` between rows, not `\n\n`. Splitting on `\n\n` will split tables mid-row and destroy structure.

**Correct Markdown-aware split priority:**
```
1. ## / ### section headers (semantic boundary — highest priority)
2. \n\n (paragraph break)
3. Sentence boundary (. or ? or !)
4. NEVER split inside a Markdown table (between | rows)
```

**Table detection:**
```typescript
function isInsideMarkdownTable(text: string, position: number): boolean {
  // Find the line containing this position
  const lineStart = text.lastIndexOf('\n', position) + 1
  const lineEnd = text.indexOf('\n', position)
  const line = text.slice(lineStart, lineEnd)
  return line.trim().startsWith('|')
}
```

## Density Filter (Noise Chunk Pre-Filter)

Before sending chunks to the classifier (SOL-007), apply a fast density check:
```typescript
function isLowDensityChunk(text: string): boolean {
  const underscoreRatio = (text.match(/_/g) || []).length / text.length
  const whitespaceRatio = (text.match(/\s/g) || []).length / text.length
  return underscoreRatio > 0.15 || whitespaceRatio > 0.70
}
// Low density → discard immediately (never sent to Haiku classifier)
// This pre-filters blank checklists (_____ lines) before the classifier even sees them
```

## ChunkOptions Type (add to shared-types)

```typescript
interface ChunkOptions {
  targetTokens?: number    // default 800
  overlapTokens?: number   // default 100
  preserveTables?: boolean // default true — never split Markdown tables
  tokenizer?: 'tiktoken' | 'gpt-tokenizer'  // default 'gpt-tokenizer' (pure JS, no native dep)
}
```

Note: Use `gpt-tokenizer` (pure JS npm package) not `tiktoken` — tiktoken requires native bindings that cause issues on Vercel.
