# P4-014: Data Integrity Admin View
**Epic:** 4.3 — LOD Enrichment + Admin
**Points:** 3 | **Depends:** P2-019 (KaizenML linting), P3-009 (graph analytics), P4-010 (GROUNDED_IN)
**Context packet:** docs/context-packets/CP-EPIC-4.3.md
**Specialist:** @frontend-specialist

**As a** superadmin
**I want** a comprehensive data integrity dashboard
**So that** I can monitor system health, catch drift, and manually trigger repairs without touching the database

## Acceptance Criteria
- Route: `/admin/data-integrity` (wires `DataIntegrityDashboard` prototype screen)
- Endpoint: `GET /api/v1/admin/data-integrity` — aggregates all health signals
- Panels:
  1. **Sync Status** — count of `sync_status='failed'` items per table, with "Reconcile" button per table
  2. **KaizenML Lint** — last 7 days of lint runs, pass/fail per rule, sparkline trends
  3. **LOD Enrichment** — SubConcepts grounded vs ungrounded, LCME elements aligned, "Run Backfill" button
  4. **Graph Health** — Neo4j node/relationship counts, PageRank last computed, orphan nodes
  5. **Generation Health** — items without tags, items without critic scores, stale running logs
- Action buttons (all POST to admin endpoints):
  - "Reconcile Sync Failures" → `POST /api/v1/admin/reconcile`
  - "Run Lint" → `POST /api/v1/admin/lint-run`
  - "Run UMLS Backfill" → `POST /api/v1/admin/umls-enrichment/backfill`
  - "Compute Graph Analytics" → `POST /api/v1/admin/graph-analytics-run`
- Auto-refresh every 60 seconds (polling — no socket needed for admin views)
