# P4-013: Faculty Onboarding Wizard
**Epic:** 4.3 — LOD Enrichment + Admin
**Points:** 3 | **Depends:** P1-024 (auth), P4-011 (admin can invite users)
**Context packet:** docs/context-packets/CP-EPIC-4.3.md
**Specialist:** @frontend-specialist

**As a** newly invited faculty member
**I want** a guided onboarding flow that walks me through uploading my first syllabus and generating my first question
**So that** I reach the "aha moment" without needing IT support

## Acceptance Criteria
- Triggered: on first login (if `user.onboarding_completed = false`)
- Route: `/onboarding` (wires existing onboarding prototype screens)
- Steps:
  1. **Welcome** — name, title, department confirmation
  2. **Your Course** — select from pre-configured courses (admin sets these) OR request new course
  3. **Upload Syllabus** — drag-drop upload, shows real-time Inngest pipeline progress
  4. **Concept Review** — review 5 extracted SubConcepts (simplified version of P2-018 queue — just first 5)
  5. **Generate First Question** — pre-filled workbench for their course, auto-sends first message
  6. **Done** — celebrate screen, link to dashboard
- Progress saved: `users.onboarding_step INTEGER` — resume from last step on refresh
- Skip option: "Skip for now" on steps 3–5 (cannot skip 1–2)
- Completion: `PATCH /api/v1/users/me/onboarding` with `{ completed: true }` → sets `onboarding_completed = true`
