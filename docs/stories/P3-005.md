# P3-005: SLO Extraction (Haiku → SLO Nodes)
**Epic:** 3.1 — Multi-Course Ingestion
**Points:** 3 | **Depends:** P3-001 (Inngest pipeline running)
**Context packet:** docs/context-packets/CP-EPIC-3.1.md
**Specialist:** @ingestion-specialist

**As a** course director
**I want** Student Learning Outcomes extracted from each syllabus and linked to the knowledge graph
**So that** I have a machine-readable map of what each course promises students will learn

## Acceptance Criteria
- New Inngest stage in pipeline: `stage 7b: extract_slos` (runs after `extract_concepts`, before `dual_write`)
- Model: Claude Haiku — prompt: `backend/src/pipeline/prompts/slo-extractor-system.txt`
- Extracts: numbered SLO statements from "Learning Objectives", "Course Outcomes", "Student Learning Outcomes" sections
- Output: array of `{ text: string, courseId: string, weekNumber?: number, bloomGuess: 1-6 }`
- Neo4j node: `SLO { uuid, text, courseUuid, weekNumber, bloomGuess, source: 'ai_extracted', createdAt }`
- Relationship: `Course -[:HAS_SLO]-> SLO`
- Supabase table: `slos (id, text, course_id FK, week_number, bloom_guess, neo4j_node_id, sync_status, created_at)`
- DualWriteService: SLOs dual-written like SubConcepts
- If syllabus has no "Learning Objectives" section: emit TEXT_MESSAGE warning, skip gracefully
