# P4-003: Per-Item Analytics View
**Epic:** 4.1 — Item Bank + Management
**Points:** 3 | **Depends:** P4-001 (item bank), P2-004 (critic), P2-015 (Toulmin), P3-018 (UMLS)
**Context packet:** docs/context-packets/CP-EPIC-4.1.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** a detailed analytics panel for each question showing all metadata, quality scores, and provenance
**So that** I can understand exactly how a question was generated and why it was scored the way it was

## Acceptance Criteria
- Route: `/items/:id` (wires existing `QuestionDetail` prototype screen)
- Endpoint: `GET /api/v1/items/:id` — returns full `QuestionDetail` shape (see 06_SCREEN_BACKEND_MAP.md) plus Phase 2/3/4 enrichments
- 5 collapsible panels in detail view:
  1. **Question** — vignette + stem + options (read-only, with "Edit" button → `/items/:id/edit`)
  2. **Quality Scores** — 6 Critic metrics as radar chart (Recharts), composite score, validation results accordion
  3. **Evidence Chain** — Toulmin argument (6 fields), TaskShell used, USMLE system/discipline
  4. **Provenance** — source chunk excerpt, ingestion job ID, generation log ID, pipeline version, retry count
  5. **UMLS Grounding** — SubConcept name → StandardTerm CUI + SNOMED CT ID + MeSH ID (if P3-018 ran)
- Radar chart: Recharts `<RadarChart>` with 6 metrics on axes
- `useItemDetail(itemId)` hook
