# P3-004: SubConcept Deduplication (0.92 Cosine Threshold)
**Epic:** 3.1 — Multi-Course Ingestion
**Points:** 5 | **Depends:** P3-003 (all 9 syllabi ingested, many duplicate SubConcepts exist)
**Context packet:** docs/context-packets/CP-EPIC-3.1.md
**Specialist:** @ingestion-specialist

**As a** system
**I want** near-duplicate SubConcepts across courses merged into single canonical nodes
**So that** "Atherosclerosis" from MEDI 531 and "Atherosclerotic Disease" from MEDI 534 resolve to one concept

## Acceptance Criteria
- One-time dedup script + ongoing dedup in `ConceptExtractorNode` on new ingest
- Script: `scripts/dedup-subconcepts.ts`
- Algorithm:
  1. Embed all SubConcept names (Voyage AI — name-level embedding, not chunk embedding)
  2. Cluster by cosine similarity ≥ 0.92
  3. Within each cluster: keep the node with the most `TEACHES` edges (canonical)
  4. Merge all other nodes: redirect their `TEACHES`, `TARGETS`, `MAPPED_TO` edges to the canonical node
  5. Delete merged nodes from Neo4j; update `sub_concepts.canonical_id` in Supabase
- New Supabase column: `sub_concepts.canonical_id UUID` — null = this IS canonical; set = points to canonical
- Supabase table: `sub_concept_dedup_log (id, merged_node_id, canonical_node_id, similarity, merged_at)`
- Edge migration Cypher:
  ```cypher
  MATCH (merged:SubConcept {uuid: $mergedUuid})<-[r:TEACHES]-(cc:ContentChunk)
  MATCH (canonical:SubConcept {uuid: $canonicalUuid})
  MERGE (cc)-[:TEACHES]->(canonical)
  DELETE r
  ```
- Ongoing: `ConceptExtractorNode` checks similarity before creating new SubConcept (threshold 0.92) — reuses canonical if match found
- After dedup: `MATCH (sc:SubConcept) RETURN count(sc)` should drop ~20–40% from pre-dedup count
