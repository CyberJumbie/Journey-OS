# P3-010: Gap-to-Generation Closed Loop
**Epic:** 3.2 — USMLE Gap Detection
**Points:** 3 | **Depends:** P3-007 (heatmap), P3-008 (priorities), P1-026 (workbench)
**Context packet:** docs/context-packets/CP-EPIC-3.2.md
**Specialist:** @frontend-specialist

**As a** course director
**I want** to click a gap cell in the heatmap and be taken directly to the workbench with that gap pre-filled
**So that** filling coverage gaps is one click, not a 5-step workflow

## Acceptance Criteria
- Heatmap cell click → navigates to `/workbench?system={system}&discipline={discipline}&courseId={id}`
- Workbench reads URL params on mount → `useCopilotReadable` injects context: `"Generate a {discipline} question covering {system} for {courseName}"`
- CopilotKit auto-sends the pre-filled message on mount (no user needs to type)
- URL param handling in `frontend/src/app/(faculty)/workbench/page.tsx`
- `useGapPreFill(searchParams)` hook — extracts params, builds prompt string
- After question approved: heatmap cell updates (re-fetch or optimistic update)
- "Generate for gap" also available from the gap priorities list (`/analytics/gaps` page)
- Visual: clicked cell gets a "Generating..." shimmer until workbench route loads

## Files to Create
