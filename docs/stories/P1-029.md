## Acceptance Criteria
- /items — table of assessment_items
- Columns: vignette (100 chars), stem (80 chars), Bloom level, USMLE system, status, date
- Filter by: course, status
- Sort by: date desc (default)
- Click row → expand full question + 5 options
- Pagination: 20 per page
