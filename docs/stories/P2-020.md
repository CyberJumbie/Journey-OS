# P2-020: Golden Dataset + Nightly Regression
**Epic:** 2.4 — Data Quality + Faculty Trust
**Points:** 3 | **Depends:** P2-019 (Inngest cron exists), P2-004 (critic scores)
**Context packet:** docs/context-packets/CP-EPIC-2.4.md
**Specialist:** @backend-specialist

**As a** developer
**I want** a set of 25 verified high-quality questions used as a regression benchmark
**So that** I can detect if pipeline changes degrade generation quality

## Acceptance Criteria
- Supabase table: `golden_dataset (id, item_id FK, added_by, added_at, notes, target_critic_min FLOAT)`
- Seed script: `seeder/src/seed-golden-dataset.ts`
  - Selects 25 items: `status = 'approved' AND critic_composite_score >= 4.0` ordered by composite desc
  - Inserts into `golden_dataset` with `target_critic_min = 3.8` (tolerance band)
- Inngest nightly function: `backend/src/inngest/golden-regression.function.ts`
  - Re-runs critic_agent on all 25 golden items (not full pipeline, just critic scoring)
  - Flags any item where new critic score < `target_critic_min`
  - Stores results in `kaizen_lint_runs` with `rule_id: 'golden_regression'`
  - Socket.io alert if any regression detected
- Admin endpoint: `GET /api/v1/admin/golden-dataset` — shows items + latest regression scores
