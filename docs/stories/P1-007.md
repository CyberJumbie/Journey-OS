## Story

so that `apps/web` and `apps/server` share one source of truth for all data shapes.

## Critical: WorkbenchState Fields (minimum)

```typescript
// packages/shared-types/src/pipeline.ts
export interface WorkbenchState {
  mode: GenerationMode
  courseId: string
  targetConcepts: string[]
  vignette: string
  stem: string
  options: Option[]
  validationResults: ValidationResult[]
  status: 'idle' | 'running' | 'complete' | 'error'
  criticScores: CriticScore | null    // Phase 2+, null in Phase 1
  generationLogId: string | null
}

export type GenerationMode = 'single' | 'bulk' | 'review'
export type PipelineNode = 'init' | 'context_compiler' | 'vignette_builder' | 'stem_writer' | 'distractor_generator' | 'validator' | 'graph_writer'
```

WorkbenchState is the critical shared contract — it's the state schema between LangGraph.js pipeline and CopilotKit frontend. Both apps import from this file.
