# P3-002: PPTX Parser (Slide Extraction + Speaker Notes)
**Epic:** 3.1 — Multi-Course Ingestion
**Points:** 5 | **Depends:** P1-010 (PdfParserFactory pattern), P3-001 (Inngest pipeline)
**Context packet:** docs/context-packets/CP-EPIC-3.1.md
**Specialist:** @ingestion-specialist

**As a** faculty member
**I want** to upload PPTX lecture slides and have them parsed alongside syllabi
**So that** the knowledge graph includes lecture content, not just formal syllabus text

## Acceptance Criteria
- New parser: `backend/src/ingestion/parsers/PptxParser.ts` implements `IPdfParser` interface
- Library: `npm install pptx-text-extract` or `officegen` — use `pptx-text-extract` (lighter)
- Extraction: per-slide text + speaker notes concatenated as `"[Slide N]\n{slideText}\n[Notes]\n{notes}"`
- Image slides (no text): emit TEXT_MESSAGE warning, skip slide (do not error)
- Output: same `ParsedDocument` type as PDF parsers — array of `{ text, pageNumber, metadata }`
- PdfParserFactory: detect `.pptx` extension → return `PptxParser` instance
- Chunking: `[Slide N]` markers used as preferred split boundaries (prefer not to split mid-slide)
- Metadata: `{ source: 'pptx', slideNumber: N, hasNotes: boolean }` stored in `content_chunks.metadata JSONB`
- Max file size: 100MB (PPTX can be large with embedded images)
