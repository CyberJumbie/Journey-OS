# P1-004: Supabase DDL — Phase 1 Core Tables

**Epic:** 1.1 — Infrastructure & Spike
**Priority:** P0
**Points:** 3
**Status:** ready
**Depends on:** P1-002

---

## Story

As a **developer**,
I want all 9 Phase 1 Supabase tables created with RLS policies, indexes, and the pgvector HNSW index,
so that every ingestion and generation story has a working schema to write to.

---

## Acceptance Criteria

- [ ] **AC1:** All 9 tables created: `institutions`, `user_profiles`, `courses`, `uploads`, `content_chunks`, `content_chunk_embeddings`, `assessment_items`, `options`, `generation_logs`
- [ ] **AC2:** RLS enabled on all tables; faculty can only read/write their institution's data
- [ ] **AC3:** HNSW index created: `CREATE INDEX ON content_chunk_embeddings USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64)`
- [ ] **AC4:** `user_profiles.role` ENUM: `faculty | institutional_admin | student | advisor | superadmin`
- [ ] **AC5:** `assessment_items.status` ENUM: `draft | pending_review | approved | rejected | retired`
