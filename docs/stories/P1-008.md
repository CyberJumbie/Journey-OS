# P1-008: CopilotKit + LangGraph.js Integration Spike

**Epic:** 1.1 — Infrastructure & Spike
**Priority:** P0
**Points:** 5
**Status:** ready
**Depends on:** P1-001, P1-007
**Source:** 03_STORY_BACKLOG_PHASE1.md § P1-008

---

## Story

As a **developer**,
I want to validate that CopilotKit can consume LangGraph.js state deltas over SSE,
so that the entire frontend architecture is de-risked before we build on it.

---

## Acceptance Criteria

- [ ] **AC1:** Minimal LangGraph.js `StateGraph` on Express server with ONE node; node updates a single string field and emits STATE_DELTA
- [ ] **AC2:** CopilotKit Runtime configured on Express (`@copilotkit/runtime`) at `POST /api/copilotkit`
- [ ] **AC3:** SSE transport working between server and client
- [ ] **AC4:** `useCoAgent` hook in a minimal React page consumes STATE_DELTA and renders the updated field
- [ ] **AC5:** `TEXT_MESSAGE` events stream to `CopilotChat` component
- [ ] **AC6:** Spike in a separate branch or directory — not polluting the main app structure
- [ ] **AC7:** Spike verdict documented in `docs/spikes/spike-001-copilotkit.md` — PASS or FAIL + findings

---
