# P2-009: Conversational Refinement
**Epic:** 2.2 — Review Mode + Bulk Generation
**Points:** 3 | **Depends:** P2-007 (review mode pipeline), P2-008 (review UI)
**Context packet:** docs/context-packets/CP-EPIC-2.2.md
**Specialist:** @pipeline-specialist

**As a** faculty member
**I want** to refine a question using natural language instructions
**So that** I can say "make distractors harder" and get an improved version without re-generating from scratch

## Acceptance Criteria
- Targeted re-run: apply_edit node analyzes instruction → determines which section to regenerate
  - "make vignette shorter" → re-run only `vignette_builder` with vignette-only context
  - "harder distractors" → re-run only `distractor_generator`
  - "change the correct answer to B" → targeted edit, no regeneration needed
  - "everything looks wrong" → full regeneration (re-enter from `context_compiler`)
- Instruction parser: simple keyword matching in `ApplyEditNode` — no LLM needed for routing
- Partial re-run: `graph.ts` supports mid-graph entry points (pass existing state, skip completed nodes)
- Prompt injection: edit instruction appended to the relevant node's system prompt on re-run
- `useCopilotAction` hook: `applyRefinement(instruction)` — sends action to CopilotKit Runtime
- Streaming: refined sections stream exactly like original generation (STATE_DELTA)
- Re-runs validator + critic automatically after refinement

## Files to Modify
- `backend/src/pipeline/nodes/ApplyEditNode.ts` — add instruction parser
- `backend/src/pipeline/graph.ts` — add mid-graph entry point support
- `frontend/src/hooks/useWorkbench.ts` — add `applyRefinement` action
