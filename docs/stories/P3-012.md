# P3-012: CoverageMapView (D3 Force-Directed Graph)
**Epic:** 3.3 — Faculty Dashboard + Coverage Visualization
**Points:** 8 | **Depends:** P3-004 (deduped SubConcepts), P3-009 (PageRank scores), P1-015 (MAPS_TO edges)
**Context packet:** docs/context-packets/CP-EPIC-3.3.md
**Specialist:** @frontend-specialist

**As a** course director
**I want** a visual force-directed graph showing SubConcepts colored by question coverage
**So that** I can see the shape of my curriculum and immediately identify dark spots

## Acceptance Criteria
- Route: `/analytics/coverage-map` (new screen — NOT in prototype, build from scratch)
- D3.js force simulation: `npm install d3` in frontend
- Nodes: SubConcept nodes, sized by `pagerank_score`, colored by coverage:
  - Green `#69a338`: ≥ 2 approved questions
  - Amber `#f59e0b`: 1 question
  - Red `#d32f2f`: 0 questions (gap)
  - Gray `#d1d5db`: not yet covered by any MAPS_TO
- Edges: `MAPS_TO` edges (SubConcept → USMLE_System) — shown as light gray lines
- Interaction: hover → tooltip with `{ name, questionCount, bloomLevels, usmleSystem }`
- Interaction: click node → side panel shows concept detail + "Generate question →" button
- Filters: by USMLE System (filter to show only one system's subgraph)
- API: `GET /api/v1/analytics/coverage-graph?courseId=X` — returns nodes + edges for D3
  ```typescript
  interface CoverageGraphData {
    nodes: { id: string; name: string; pagerank: number; questionCount: number; usmleSystem: string }[];
    edges: { source: string; target: string; type: string }[];
  }
  ```
- God Component rule: `CoverageMapView.tsx` must split into `ForceGraph`, `ConceptTooltip`, `ConceptDetailPanel`
- Performance: render max 500 nodes; if > 500, show top by pagerank
