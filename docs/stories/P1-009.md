# P1-009: File Upload Endpoint
**Epic:** 1.2 — Single Course Ingestion
**Points:** 3 | **Depends:** P1-004 (tables exist)
**Context packet:** docs/context-packets/CP-EPIC-1.2.md

**As a** faculty member
**I want** to upload my course syllabus
**So that** the system can extract concepts from my curriculum

## Acceptance Criteria
- `POST /api/v1/uploads` — multipart/form-data, PDF only, max 50MB
- Stores in Supabase Storage `raw-uploads` bucket
- Storage path: `{institution_id}/{course_id}/{upload_id}/{original_filename}`
- WORM: write-once, no overwrites via API
- Creates `uploads` row, `status: 'pending'`
- Returns `{ upload_id, status: 'pending' }`
- Auth: JWT with `role: 'faculty'` or `role: 'institutional_admin'`

## Files to Create
- backend/src/routes/upload.routes.ts
- backend/src/controllers/upload.controller.ts
- backend/src/services/upload.service.ts
- backend/src/repositories/upload.repository.ts

```bash
curl -X POST http://localhost:3001/api/v1/uploads \
```
