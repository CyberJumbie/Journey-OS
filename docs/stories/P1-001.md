## Story

As a **developer**,
I want a Turborepo monorepo with the correct package structure,
so that all apps and packages share types, configs, and build tooling from day one.

---

## Acceptance Criteria

- [ ] **AC1:** Turborepo root with `turbo.json` configured for `build`, `lint`, `type-check`, `dev`
- [ ] **AC2:** `apps/web` — Next.js 15 App Router, React 19, TypeScript strict, Tailwind CSS 4, shadcn/ui New York style initialized
- [ ] **AC3:** `apps/server` — Express.js + TypeScript, `ts-node-dev` for hot reload, with `cors` + `helmet` + `compression`
- [ ] **AC4:** `packages/shared-types` — TypeScript barrel exports, importable in both apps
- [ ] **AC5:** `packages/ui` — shared React component library (initially empty, shadcn/ui wrapper)
- [ ] **AC6:** Root scripts: `dev` (starts web:3000 + server:3001 concurrently), `build`, `lint`, `type-check`
- [ ] **AC7:** `pnpm dev` starts both apps with no errors

## Key Implementation Notes

- Start from `create-turbo`, then customize
- Tailwind 4: CSS-first config — `@import "tailwindcss"` in `globals.css` (NOT `tailwind.config.ts`)
- shadcn/ui: `npx shadcn@latest init`, select **New York** style
- Root `tsconfig.base.json` with strict mode + path aliases
- Root `.gitignore`, `.eslintrc`, `.prettierrc`
- `packages/ui` is empty initially — just the package scaffold
