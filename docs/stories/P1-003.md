## Story

I want environment configuration, API keys, and CI skeleton,
so that both apps can connect to services and CI validates every push.

## ⚠️ Naming Corrections

The env var is `NEO4J_USER` — **not** `NEO4J_USERNAME`. Check this before writing env validation.

The Zod config file is `apps/server/src/config.ts` — **not** `apps/server/src/config/env.ts`.

The turbo command is `type-check` (hyphenated) — **not** `typecheck`.

## Key Implementation

```typescript
// apps/server/src/config.ts
import { z } from 'zod'

const EnvSchema = z.object({
  NODE_ENV: z.enum(['development', 'production', 'test']).default('development'),
  PORT: z.string().default('3001'),
  NEO4J_URI: z.string().startsWith('neo4j'),
  NEO4J_USER: z.string().min(1),         // NOTE: NEO4J_USER not NEO4J_USERNAME
  NEO4J_PASSWORD: z.string().min(1),
  SUPABASE_URL: z.string().url(),
  SUPABASE_SERVICE_ROLE_KEY: z.string().min(1),
  ANTHROPIC_API_KEY: z.string().startsWith('sk-ant-'),
  VOYAGE_API_KEY: z.string().min(1),
})

export const config = EnvSchema.parse(process.env)
// Throws with clear error message on missing/invalid vars at server startup
```
