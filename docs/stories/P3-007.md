# P3-007: 16×7 USMLE Coverage Heatmap
**Epic:** 3.2 — USMLE Gap Detection
**Points:** 5 | **Depends:** P3-003 (all courses ingested), P1-015 (MAPS_TO edges exist), P1-006 (USMLE nodes seeded)
**Context packet:** docs/context-packets/CP-EPIC-3.2.md
**Specialist:** @backend-specialist

**As a** course director
**I want** a 16×7 heatmap showing question coverage by USMLE System (16 rows) × Discipline (7 columns)
**So that** I can see at a glance which system-discipline combinations have no questions yet

## Acceptance Criteria
- 16 USMLE Systems (seeded in Phase 1): Cardiovascular, Pulmonary, Renal, GI, Musculoskeletal, Reproductive, Endocrine, Hematology/Lymph, Neurology, Psychiatry/Behavioral, Dermatology, Immunology, Infectious Disease, Nutrition/Digestion, Multisystem, General Principles
- 7 USMLE Disciplines: Pathology, Physiology, Biochemistry, Pharmacology, Microbiology, Anatomy, Behavioral Science
- Cypher query (see CP-EPIC-3.2.md for full query):
  - Count `AssessmentItem` nodes (status='approved') by `USMLE_System` × `USMLE_Discipline`
  - Also count SubConcept coverage (concepts with ≥1 question vs total concepts per cell)
- API: `GET /api/v1/analytics/usmle-heatmap?courseId=X` (optional courseId filter; without = all courses)
- Response shape:
  ```typescript
  interface USMLEHeatmapData {
    systems: string[];        // 16 items
    disciplines: string[];    // 7 items
    cells: {
      system: string;
      discipline: string;
      itemCount: number;
      conceptCount: number;
      coveredConcepts: number;
      coveragePct: number;
    }[];
  }
  ```
- Controller: `backend/src/controllers/analytics.controller.ts`
- Repository: `backend/src/repositories/analytics.repository.ts` — all Cypher lives here
- Route: `GET /api/v1/analytics/usmle-heatmap`

## Files to Create
- `backend/src/controllers/analytics.controller.ts`
- `backend/src/repositories/analytics.repository.ts`
- `backend/src/routes/analytics.routes.ts`
