# P4-008: Basic Exam Delivery (Timed, Answer Recording)
**Epic:** 4.2 — Exam Assembly
**Points:** 5 | **Depends:** P4-007 (exam finalized), P1-024 (auth)
**Context packet:** docs/context-packets/CP-EPIC-4.2.md
**Specialist:** @frontend-specialist + @backend-specialist

**As a** student
**I want** to take a timed exam in the browser with my answers saved automatically
**So that** I can complete assessments and have my responses recorded for scoring

## Acceptance Criteria

### Assignment
- Route: `/exams/:id/assign` (wires `ExamAssignment` prototype screen)
- Endpoint: `POST /api/v1/exams/:id/assign` — body: `{ studentIds, startTime, endTime, durationMinutes }`
- Creates `exam_sessions` rows (one per student): `{ exam_id, student_id, status, start_time, end_time, submitted_at }`
- Students notified via Socket.io event `exam:assigned` (uses P2-012 notification system)

### Delivery
- Route: `/exams/:sessionId/take` — student-facing exam view
- Auth: student JWT required; student can only access their own session
- Timer: countdown from `durationMinutes` in browser (uses `Date.now()` — not server-dependent)
- Auto-submit: when timer reaches 0, submit current answers automatically
- Questions shown one at a time (navigable via prev/next + question grid sidebar)
- Answer recorded on each selection: `PATCH /api/v1/exam-sessions/:id/responses` — body: `{ questionId, selectedOption }` — auto-saved, no explicit "save" button
- No back-navigation after submit (confirmation modal: "Submit exam? This cannot be undone.")
- Submitted: `POST /api/v1/exam-sessions/:id/submit` → calculate score, set status='completed'

### Scoring
- Score calculated server-side on submit: count correct options, store `raw_score`, `pct_score` on `exam_sessions`
- `POST /api/v1/exam-sessions/:id/submit` returns: `{ rawScore, pctScore, correctCount, totalQuestions }`
- No item-level feedback yet (Phase 5 adds explanation + misconception panel)

### Supabase Tables
- `exams`, `exam_questions`, `exam_sessions`, `student_responses` (see CP-EPIC-4.2.md for DDL)

## Smoke Test
```bash
# Assign exam to a test student
curl -X POST "localhost:3001/api/v1/exams/{examId}/assign" \
  -H "Authorization: Bearer $FACULTY_JWT" \
  -d '{"studentIds":["student-uuid"],"startTime":"2026-04-01T09:00:00Z","durationMinutes":60}'

# Student takes exam (login as student, get session)
# Answer first question
curl -X PATCH "localhost:3001/api/v1/exam-sessions/{sessionId}/responses" \
  -H "Authorization: Bearer $STUDENT_JWT" \
  -d '{"questionId":"q-uuid","selectedOption":"b"}'

# Submit
curl -X POST "localhost:3001/api/v1/exam-sessions/{sessionId}/submit" \
  -H "Authorization: Bearer $STUDENT_JWT"
# Expected: { rawScore: 7, pctScore: 70, correctCount: 7, totalQuestions: 10 }
```
