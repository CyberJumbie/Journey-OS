# P1-024: Auth Flow
**Epic:** 1.4 — Workbench MVP
**Points:** 5 | **Depends:** P1-004 (tables), P1-001 (monorepo)
**Context packet:** docs/context-packets/CP-EPIC-1.4.md
**Specialists:** @frontend-specialist (login/register UI), @backend-specialist (auth middleware)

## Acceptance Criteria
- /login — email + password → supabase.auth.signInWithPassword()
- /register — faculty only in Phase 1
- JWT claims: { role, institution_id, is_course_director }
- Protected routes: redirect to /login if no session
- backend authMiddleware: validates JWT, attaches req.user
- Use @supabase/ssr for Next.js App Router
