# P4-010: GROUNDED_IN Quality Audit + Backfill
**Epic:** 4.3 — LOD Enrichment + Admin
**Points:** 2 | **Depends:** P3-018 (GROUNDED_IN edges exist), P2-019 (KaizenML linting)
**Context packet:** docs/context-packets/CP-EPIC-4.3.md
**Specialist:** @backend-specialist

**As a** system administrator
**I want** automated detection and backfill of missing GROUNDED_IN relationships
**So that** newly extracted SubConcepts are automatically enriched with UMLS terms without manual intervention

## Acceptance Criteria
- New KaizenML lint rule (adds to existing 5 rules → becomes rule 6):
  - `grounded_in_coverage`: SubConcepts missing `GROUNDED_IN` edge (excluding concepts added < 24h ago) → alert if > 20% ungrounded
- Auto-backfill Inngest function: `backend/src/inngest/umls-backfill.function.ts`
  - Trigger: `journey/ingest.completed` (after every new course ingested)
  - Finds new SubConcepts with no `GROUNDED_IN` edge, fires UMLS enrichment for them
  - Max 50 concepts per backfill run (rate limit guard)
- Admin endpoint: `POST /api/v1/admin/umls-enrichment/backfill?limit=50` — manual trigger
