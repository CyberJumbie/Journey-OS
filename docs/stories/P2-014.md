# P2-014: ProficiencyVariable Nodes
**Epic:** 2.3 — ECD + TaskShells
**Points:** 2 | **Depends:** P2-013 (TaskShells exist), P1-013 (SubConcepts extracted)
**Context packet:** docs/context-packets/CP-EPIC-2.3.md
**Specialist:** @backend-specialist

**As a** system
**I want** ProficiencyVariable nodes created (1:1 with SubConcepts) when SubConcepts are extracted
**So that** we have a measurable variable per concept for ECD alignment and eventual BKT tracking

## Acceptance Criteria
- ProficiencyVariable node: `uuid, name, subConceptUuid, createdAt`
- Created automatically in `ConceptExtractorNode` during ingestion (same pipeline as SubConcept extraction)
- `MAPPED_TO` relationship: `ProficiencyVariable -[:MAPPED_TO]-> SubConcept`
- `ASSESSED_BY` relationships: after creation, attempt to match to 1–3 TaskShells based on bloom_level_guess
  - Primary TaskShell (priority 1): matches Bloom range overlap
  - Secondary TaskShells (priority 2–3): adjacent Bloom ranges
- DualWriteService: ProficiencyVariable nodes dual-written (Supabase `proficiency_variables` table + Neo4j)
- Supabase table: `proficiency_variables (id UUID, name TEXT, sub_concept_id UUID FK, neo4j_node_id TEXT, created_at)`
- `scripts/validate-graph.ts`: ProficiencyVariable count ≈ SubConcept count (1:1 ratio)

## Files to Modify
- `backend/src/ingestion/ConceptExtractorNode.ts` — add ProficiencyVariable creation after SubConcept
- `backend/src/repositories/graph.repository.ts` — add `createProficiencyVariable()`, `linkAssessedBy()`
- Phase 2 migration — add `proficiency_variables` table
- `scripts/validate-graph.ts` — add ProficiencyVariable count check

## Smoke Test
```cypher
MATCH (pv:ProficiencyVariable)-[:MAPPED_TO]->(sc:SubConcept)
RETURN count(pv) AS pv_count, count(sc) AS sc_count
-- Expected: pv_count = sc_count (every SubConcept has exactly one ProficiencyVariable)

MATCH (pv:ProficiencyVariable)-[ab:ASSESSED_BY]->(ts:TaskShell)
RETURN pv.name, ts.name, ab.priority LIMIT 10
-- Expected: rows showing primary (priority 1) and secondary (priority 2-3) TaskShell links
```
