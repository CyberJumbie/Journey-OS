# P4-007: Exam Preview, Manual Swap, Finalize
**Epic:** 4.2 — Exam Assembly
**Points:** 3 | **Depends:** P4-005 (exam builder), P4-006 (MIP solver)
**Context packet:** docs/context-packets/CP-EPIC-4.2.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** to review the assembled exam, swap individual questions, and finalize it for delivery
**So that** I have final editorial control before distributing the exam to students

## Acceptance Criteria
- Route: `/exams/:id` — exam detail + preview (Step 2 of exam builder flow)
- Question list: ordered list, each row shows: position, stem excerpt, system badge, Bloom badge, difficulty badge, critic score
- Drag-to-reorder: `@dnd-kit/core` for question ordering (`npm install @dnd-kit/core @dnd-kit/sortable`)
- Swap button per question: opens `SwapQuestionModal` — searches item bank, shows top 5 alternatives matching same Bloom + system
- Manual add: "Add Question" opens item bank browser in a side sheet, filtered to compatible items
- "Finalize Exam" button → `PATCH /api/v1/exams/:id` with `{ status: 'published', questionOrder: [...] }`
- Final blueprint validation re-runs on finalize (confirms constraints still met after manual swaps)
- Supabase tables: `exams`, `exam_questions` (see CP-EPIC-4.2.md for full DDL)
- `PATCH /api/v1/exams/:id/questions/:questionId/swap` → swap with alternative
- "Export Blueprint" button → PDF/CSV of exam blueprint for accreditation records

## Smoke Test
```bash
# Get exam for preview
curl "localhost:3001/api/v1/exams/{examId}" -H "Authorization: Bearer $JWT" | jq '{name, questions: (.questions | length), status}'

# Swap question 5 with an alternative
curl -X PATCH "localhost:3001/api/v1/exams/{examId}/questions/{qId}/swap" \
  -H "Authorization: Bearer $JWT" -d '{"replacementItemId":"new-item-uuid"}'
# Expected: 200 OK, exam questions updated

# Finalize
curl -X PATCH "localhost:3001/api/v1/exams/{examId}" \
  -H "Authorization: Bearer $JWT" -d '{"status":"published"}'
# Expected: { status: "published" }
```
