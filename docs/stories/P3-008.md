# P3-008: Gap Priority Scoring Formula
**Epic:** 3.2 — USMLE Gap Detection
**Points:** 3 | **Depends:** P3-007 (heatmap data exists)
**Context packet:** docs/context-packets/CP-EPIC-3.2.md
**Specialist:** @backend-specialist

**As a** course director
**I want** each gap cell ranked by priority so I know which gaps matter most to fill first
**So that** my generation effort goes toward the highest-impact USMLE coverage holes

## Acceptance Criteria
- Priority formula (all factors 0.0–1.0, weighted sum):
  ```
  priority_score = (
    (1 - coverage_pct)      * 0.35  +   // how uncovered is it?
    usmle_step1_weight      * 0.30  +   // how heavily tested on Step 1?
    concept_centrality      * 0.20  +   // how central are these concepts in the graph?
    recency_factor          * 0.15      // how recently was curriculum updated?
  )
  ```
- `usmle_step1_weight`: hardcoded from published USMLE Step 1 content specification (see CP-EPIC-3.2.md for values)
- `concept_centrality`: uses PageRank scores from P3-009 (if not yet run, defaults to 0.5)
- `recency_factor`: based on `ContentChunk.created_at` — newer chunks = higher recency
- API: `GET /api/v1/analytics/gap-priorities?limit=20` — returns top 20 gaps sorted by priority_score
- Response: each gap includes `{ system, discipline, priorityScore, breakdown: { coverage, usmleWeight, centrality, recency } }`
- Supabase materialized view `gap_priorities` refreshed on: new item approved, new course ingested
