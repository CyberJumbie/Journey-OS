# P2-008: Review Mode UI
**Epic:** 2.2 — Review Mode + Bulk Generation
**Points:** 3 | **Depends:** P2-007 (review pipeline), P1-026 (workbench UI)
**Context packet:** docs/context-packets/CP-EPIC-2.2.md
**Specialist:** @frontend-specialist

**As a** faculty member
**I want** to open any question in the workbench in review mode with a single click
**So that** editing feels as natural as generating

## Acceptance Criteria
- Route: `/workbench?mode=review&itemId={id}` loads QuestWorkbench in review mode
- On mount: `useCopilotReadable` injects `{ mode: 'review', itemId }` into CopilotKit context
- Right panel pre-populated with existing question (vignette, stem, options) immediately on load — no wait for pipeline
- Edit indicators: modified sections highlighted in amber `var(--amber)` after apply_edit runs
- Version history panel (collapsible, bottom of right panel): list of prior versions with timestamps
- `useItemVersions(itemId)` hook — fetches `GET /api/v1/items/:id/versions`
- Review mode badge in header: amber pill "Review Mode — [question excerpt]"
- "Save Changes" button → `PATCH /api/v1/items/:id` with new content
- "Discard" button → reload original from Supabase
- Atoms needed: `VersionBadge`, `EditHighlight` (wraps text, amber border on change)
- Max 150 lines per component (God Component rule)
