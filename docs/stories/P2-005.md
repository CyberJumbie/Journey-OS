# P2-005: review_router Node
**Epic:** 2.1 — Pipeline Completion
**Points:** 2 | **Depends:** P2-004 (critic scores available)
**Context packet:** docs/context-packets/CP-EPIC-2.1.md
**Specialist:** @pipeline-specialist

**As a** faculty member
**I want** the system to automatically approve high-quality questions and route borderline ones to me
**So that** I only spend review time on questions that actually need human judgment

## Acceptance Criteria
- Node: `backend/src/pipeline/nodes/ReviewRouterNode.ts` — final node, after critic_agent
- Pure TypeScript — no AI calls
- Routing logic:
  - `auto_approve`: `critic_composite ≥ 4.0` AND `validation_passed = true` AND `dedup_status ≠ 'auto_reject'`
  - `auto_reject`: `validation_passed = false` AND one BLOCKING rule failed (R001–R005 from Phase 1) OR `dedup_status = 'auto_reject'`
  - `faculty_review`: everything else (composite 3.0–3.9, warnings, dedup flags)
- Actions:
  - `auto_approve` → update `assessment_items.status = 'approved'` via DualWriteService
  - `auto_reject` → update `status = 'rejected'`, set `rejection_reason`
  - `faculty_review` → status stays `'draft'`, TEXT_MESSAGE explains why review needed
- STATE_DELTA: `{ autoRoute: 'auto_approve' | 'auto_reject' | 'faculty_review', pipelineStatus: 'completed' }`
- TEXT_MESSAGE: "Auto-approved ✓" OR "Sent to review queue — composite score 3.2/5.0" OR "Auto-rejected: [reason]"
- Supabase: write `auto_route` column on `assessment_items`
