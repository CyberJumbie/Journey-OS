## Story

As a **system**,
I want to extract medical SubConcepts from course content and link them to the course in Neo4j,
so that the generation pipeline has a concept map to target when creating questions.

---

## Acceptance Criteria

- [ ] **AC1:** Classifier node runs first — `classifierNode(chunks)` splits into `{ academic, noise, borderline }`
- [ ] **AC2:** Concept extraction runs ONLY on `academic` chunks — never on `noise` chunks
- [ ] **AC3:** For each academic chunk: Haiku extracts 2–8 SubConcept names per chunk (specific, clinical — not "Introduction" or "Overview")
- [ ] **AC4:** Each SubConcept written to Supabase + Neo4j via DualWriteService
- [ ] **AC5:** `ContentChunk -[:TEACHES]-> SubConcept` edge created in Neo4j for each extracted concept
- [ ] **AC6:** `generation_logs.pipeline_state` records classifier stats: `{ academic_count, noise_count, borderline_count, noise_ratio }`
- [ ] **AC7:** Alert logged if `noise_ratio > 0.60` (indicates PDF extraction likely failed — Markdown not preserved)

## Pipeline: Two-Stage Processing

### Stage 1 — Classify (route, don't extract)
```typescript
// apps/server/src/pipeline/nodes/classifier.node.ts (see SOL-007)
const { academic, noise, borderline } = await classifierNode(chunks)

// Log stats
const noise_ratio = noise.length / chunks.length
if (noise_ratio > 0.60) {
  console.error('⚠️ High noise ratio — PDF extraction may have failed (not Markdown)')
}
```

### Stage 2 — Extract (only from academic chunks)
```typescript
// apps/server/src/pipeline/nodes/concept-extractor.node.ts
// One Haiku call per chunk (or batched if possible)
for (const chunk of academic) {
  const concepts = await extractConcepts(chunk)  // prompt in pipeline/prompts/concept-extractor-system.txt
  for (const concept of concepts) {
    await dualWriteService.writeSubConcept({ name: concept, chunkId: chunk.id, courseId })
    await neo4jSession.run(
      `MATCH (c:ContentChunk {uuid: $chunkUuid})
       MATCH (s:SubConcept {uuid: $conceptUuid})
       MERGE (c)-[:TEACHES]->(s)`,   // TEACHES: ContentChunk → SubConcept (not Course → SubConcept)
      { chunkUuid: chunk.neo4j_node_id, conceptUuid: concept.uuid }
    )
  }
}
```

## Critical Relationship Direction

```
ContentChunk -[:TEACHES]-> SubConcept

NOT: Course -[:TEACHES]-> SubConcept
NOT: SubConcept -[:TEACHES]-> ContentChunk
```

The CHUNK is the source of teaching evidence. The SubConcept is what is taught. See GRAPH_SCHEMA.md.
