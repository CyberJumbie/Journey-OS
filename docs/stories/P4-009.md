# P4-009: StandardTerm → LCME_Element Alignment (UMLS Phase 4 Extension)
**Epic:** 4.3 — LOD Enrichment + Admin
**Points:** 3 | **Depends:** P3-018 (StandardTerm nodes exist with CUI), P1-006 (LCME_Element nodes seeded)
**Context packet:** docs/context-packets/CP-EPIC-4.3.md
**Specialist:** @backend-specialist

> **Note:** Core UMLS enrichment (StandardTerm node creation, CUI/SNOMED/MeSH lookup) was completed in P3-018.
> This story adds the Phase 4 extension: linking StandardTerm nodes to LCME_Elements via shared vocabulary,
> and extending the admin UI with enrichment quality metrics.

**As an** Associate Dean
**I want** LCME elements to be directly linked to UMLS standard terms
**So that** the compliance chain can be verified by external auditors using internationally recognized identifiers

## Acceptance Criteria

### LCME_Element → StandardTerm Alignment
- For each LCME_Element node, attempt CUI-based lookup via UMLS NLM API
- Relationship: `LCME_Element -[:USES_TERM]-> StandardTerm`
- Fallback: if no direct CUI match, link via SubConcept bridge: `LCME_Element ← ALIGNS_TO ← ILO ← FULFILLS ← SLO ← MAPS_TO ← SubConcept -[:GROUNDED_IN]-> StandardTerm`
- Script: `scripts/align-lcme-terms.ts` — one-time run after P3-018 completes
- Cypher:
  ```cypher
  MATCH (lcme:LCME_Element {elementId: $elementId})
  MATCH (st:StandardTerm {cui: $cui})
  MERGE (lcme)-[:USES_TERM]->(st)
  ```

### Admin Enrichment Dashboard Extension
- Endpoint: `GET /api/v1/admin/lod-enrichment/status` — combines UMLS enrichment status with LCME alignment
- Response: `{ subConceptsEnriched, subConceptsTotal, lcmeElementsAligned, lcmeElementsTotal, lastRunAt }`
- Admin panel: "LOD Enrichment" section shows both progress bars

### Enhanced Evidence Chain
When both P3-018 and P4-009 complete, the evidence chain query can use:
```cypher
MATCH (lcme:LCME_Element)-[:USES_TERM]->(st:StandardTerm)<-[:GROUNDED_IN]-(sc:SubConcept)<-[:TARGETS]-(ai:AssessmentItem {status:'approved'})
RETURN lcme.elementId, st.cui, count(DISTINCT ai) AS evidence_count
```
