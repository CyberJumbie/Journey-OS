# P3-017: Evidence Export (CSV + Structured JSON)
**Epic:** 3.4 — LCME Compliance MVP
**Points:** 3 | **Depends:** P3-016 (evidence chain query)
**Context packet:** docs/context-packets/CP-EPIC-3.4.md
**Specialist:** @backend-specialist

**As an** Associate Dean
**I want** to export complete LCME evidence in CSV and JSON formats
**So that** I can submit compliance documentation to accreditors in < 60 seconds

## Acceptance Criteria
- Endpoint: `GET /api/v1/admin/lcme/export?format=csv|json`
- CSV format: one row per evidence item
  ```
  lcme_standard, element_id, element_name, ilo_name, slo_text, course_code,
  subconcept_name, item_id, item_stem_excerpt, item_status, critic_score, approved_date
  ```
- JSON format: structured by standard → element → chain (same as drill-down response, all elements)
- Generation: run full coverage chain query for ALL 93 elements in one pass (< 60 seconds SLA)
- Streaming: stream CSV rows as generated — do not buffer full file in memory
- Filename: `journey-os-lcme-evidence-{YYYY-MM-DD}.csv`
- Background job option: if generation > 5 seconds, fire Inngest job, email link when ready
- Button in LCME dashboard: "Export Evidence" → triggers download or job

## Files to Modify
- `backend/src/controllers/lcme.controller.ts` — add export endpoint
- `backend/src/repositories/lcme.repository.ts` — add full-corpus query
- `backend/src/inngest/lcme-export.function.ts` — async export job

## Smoke Test
```bash
# Export all LCME evidence as CSV
curl "localhost:3001/api/v1/admin/lcme/export?format=csv" \
  -H "Authorization: Bearer $ADMIN_JWT" -o lcme-evidence.csv

# Check: rows present, headers match spec, response time < 60 seconds
time wc -l lcme-evidence.csv
# Expected: > 1 row (header + data), total time < 60s

# JSON export
curl "localhost:3001/api/v1/admin/lcme/export?format=json" \
  -H "Authorization: Bearer $ADMIN_JWT" | jq '.standards | length'
# Expected: 12
```
